# UCS 8.2.1 category keys

`ucs-8.2.1.tsv` contains CatID, English category and English subcategory,
sorted by CatID: 753 entries across 82 categories. Indices are part of schema 17;
changing their order requires a migration. Original filenames are never changed.

The [official UCS site](https://universalcategorysystem.com/) identifies UCS as
a public-domain initiative by Tim Nielsen, Justin Drury, Kai Paquin and the
community. Its January 2024 8.2.1 notice corrects WOOD-HANDLE to `WOODHndl`.
Terms/version checked on 2026-10-20. No application license is inferred from this
data's status.

The official resource link points to Dropbox. The reduced table was generated
from the English CSV mirror maintained by
[jmrsound/ucs-tools](https://github.com/jmrsound/ucs-tools/blob/main/src/ucs_tools/data/ucs_v8.2.1.csv),
which records its official-list provenance in `PROVENANCE.md`. SHA-256 of the
downloaded CSV:
`aebc8bf4f8b0dd7cafc1231c25b6664250087ab1acb8d4e6ed18ef8bf9d47986`.
Definitions, synonyms, translations and tool source code are not bundled.
Builds/tests never fetch this data.
