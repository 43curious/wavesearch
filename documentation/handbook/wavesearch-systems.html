SOUND RETRIEVAL AND AUDITION SUBSYSTEM
2.1.1

INTRODUCTION.

WaveSearch locates sound effects through a local catalog while original audio remains in its library folders. The native macOS station searches, auditions and supplies media references to an editor (figure 2.1-1).

2.1.2

FUNCTIONAL DESCRIPTION.

A scan publishes a searchable snapshot. Lexical search uses filenames and metadata; acoustic search uses an example. Optional CLAP adds semantic matches. Selection prepares preview audio off the interface thread. Background refinement yields to foreground work.

2.1.2.1

Media Reference Rule.

“Keep the files in place” supplies the full original URL, even for a selected range. “Copy files to Exports” copies whole files or renders ranges (figure 2.1-2).
